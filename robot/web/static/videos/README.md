# วิดีโอโหมดรอ

วางไฟล์วิดีโอ (`.mp4` / `.webm`) ไว้ในโฟลเดอร์นี้ ตอนไม่มีใครใช้หุ่นนานเกิน `IDLE_VIDEO_SECONDS` (ตั้งใน `robot/config.py`, ค่าเริ่มต้น 90 วินาที) จอเนื้อหาจะเปิดวิดีโอเต็มจอ

- มีหลายไฟล์ → เล่นต่อกันตามลำดับชื่อไฟล์ แล้ววนกลับไฟล์แรก (ตั้งชื่อ `01-...mp4`, `02-...mp4` เพื่อกำหนดลำดับ)
- ไม่มีไฟล์เลย → โชว์ตราวิทยาลัย + "แตะจอเพื่อถามหุ่นยนต์" แทน
- แตะจอ หรือเซนเซอร์เจอคน → ปิดวิดีโอ กลับหน้าถามตอบ (เริ่มคุยใหม่)
- ใช้ไฟล์ `.mp4` แบบ H.264 จะเล่นบน Raspberry Pi ได้ลื่นที่สุด ความละเอียด 720p พอ (ไฟล์เล็ก ไม่กิน CPU)

ไฟล์วิดีโอไม่ขึ้น git (ใหญ่) — ก๊อปไปวางที่ Pi เอง
