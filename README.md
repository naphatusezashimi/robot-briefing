# 🤖 หุ่นยนต์แนะนำข้อมูลวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์

หุ่นยนต์ **"กล่องพูดได้"** สำหรับตั้งที่วิทยาลัย ให้ผู้มาติดต่อ **พูดถามข้อมูลแล้วได้คำตอบเป็นเสียงภาษาไทย** — เรื่องหลักสูตร การรับสมัคร การติดต่อ และอื่นๆ

> 🎯 **หัวใจของระบบ:** ตอบจากฐานข้อมูลวิทยาลัยเท่านั้น **ไม่ตอบมั่ว** — ถ้าไม่มีข้อมูล จะบอกให้ติดต่อเจ้าหน้าที่ (โทร 0-3628-1295)

## ✨ ความสามารถ

- 🎤 **พูดถาม–พูดตอบ** ภาษาไทย (Web Speech API ของเบราว์เซอร์ — ฟรี)
- ⌨️ **พิมพ์ถามได้** เป็นตัวสำรอง (เผื่อคนไม่อยากพูด)
- 😊 **จอใบหน้าแสดงอารมณ์** (รอ / ฟัง / คิด / ตอบ / ผิดพลาด) + จอแชทแสดงบทสนทนา
- 🧠 ใช้ AI (**Gemini** ฟรีเป็นค่าเริ่มต้น / สลับเป็น **Claude** ได้) ตอบโดยอ้างอิง `college_data.json` + `saraburi_data.json` เท่านั้น
- 🏞️ **ตอบเรื่องสระบุรี** — สถานที่ท่องเที่ยว + สินค้า OTOP
- 🗺️ **แสดงแผนที่วิทยาลัย** อัตโนมัติเมื่อถามทาง/ตำแหน่งอาคาร + เสียงตอบผู้หญิง
- 👆 **ปุ่มคำถามยอดฮิต** กดถามได้ทันที
- 🔘 **ปุ่มกดจริง (GPIO)** บน Raspberry Pi กดแล้วเริ่มฟังเสียง + เปิดเครื่องแล้วรันเองแบบเต็มจอ (kiosk)

## 🤖 หน้าตาของสิ่งประดิษฐ์

**ตู้/กล่องรูปหุ่นยนต์** สูงประมาณโต๊ะ ตั้งที่ประชาสัมพันธ์หรือหน้าอาคาร

```
        ┌─────────────────┐
        │   ◉        ◉    │  ← หัว: จอใบหน้า (/face)
        │      ‿‿‿        │     ตาขยับ เปลี่ยนอารมณ์ได้
        └────────┬────────┘
     ┌───────────┴───────────┐
     │ ┌───────────────────┐ │
     │ │ 💬 ถาม: สาขามีอะไร │ │  ← ตัว: จอ touch screen (/screen)
     │ │ 🤖 มีช่างยนต์ ...   │ │     แสดงแชท กด/พิมพ์ได้
     │ │ [🎤] [พิมพ์...]    │ │
     │ └───────────────────┘ │
     │        ( 🔴 )         │  ← ปุ่มกดจริง (GPIO) กดแล้วพูดได้เลย
     │      🔊 ลำโพง 🎤 ไมค์  │
     │   [Raspberry Pi ข้างใน]│  ← สมองซ่อนในกล่อง
     └───────────────────────┘
```

### 🔧 ชิ้นส่วน

| ชิ้นส่วน | หน้าที่ |
|---|---|
| **Raspberry Pi** | สมอง ซ่อนในกล่อง รันโปรแกรมทั้งหมด |
| **จอ touch screen** | ติดตรงลำตัว แสดงแชท กดปุ่ม อ่านคำตอบ |
| **จอใบหน้า** | ติดตรงหัว แสดงตาหุ่น (จอเล็กราคาถูกได้ ไม่ต้องสัมผัส) |
| **ปุ่มกดใหญ่** | กดแล้วหุ่นเริ่มฟัง |
| **ไมค์ + ลำโพง** | รับเสียงคนถาม / พูดตอบ |
| **WiFi** | ให้ Pi ต่อไปถาม AI (Gemini) |

### 🎬 การใช้งานจริง

1. **เสียบปลั๊ก** → Pi เปิดเอง ขึ้นหน้าจอเอง ไม่ต้องมีคนมากด
2. คนเดินมา **กดปุ่ม** แล้วพูด *"วิทยาลัยมีสาขาอะไรบ้าง"*
3. **ตาหุ่นเปลี่ยน** เป็นท่าฟัง → ท่าคิด
4. หุ่น **พูดตอบด้วยเสียงผู้หญิง** + จอตัวขึ้นคำตอบเป็นตัวหนังสือ
5. ถามทาง เช่น *"โรงอาหารอยู่ไหน"* → **ขึ้นแผนที่** ด้วย
6. ถามเรื่องที่ไม่มีข้อมูล → **บอกให้ติดต่อเจ้าหน้าที่** ไม่แต่งเอง

## 🚀 เริ่มใช้งานเร็ว

```bash
cd robot
pip install -r requirements.txt
```

ใส่ `GEMINI_API_KEY` ในไฟล์ `robot/.env` แล้ว **ดับเบิลคลิก `robot/web/run_web.bat`**
→ เปิด Chrome ที่ `http://127.0.0.1:5000/screen` (จอแชท) และ `/face` (จอใบหน้า)

```

mockups/              แบบหน้าจอ (ดีไซน์ UI)

```
