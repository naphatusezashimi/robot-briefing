# 🤖 หุ่นยนต์แนะนำข้อมูลวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์

หุ่นยนต์ **"กล่องพูดได้"** สำหรับตั้งที่วิทยาลัย ให้ผู้มาติดต่อ **พูดถามข้อมูลแล้วได้คำตอบเป็นเสียงภาษาไทย** — เรื่องหลักสูตร การรับสมัคร การติดต่อ และอื่นๆ

> 🎯 **หัวใจของระบบ:** ตอบจากฐานข้อมูลวิทยาลัยเท่านั้น **ไม่ตอบมั่ว** — ถ้าไม่มีข้อมูล จะบอกให้ติดต่อเจ้าหน้าที่ (โทร 0-3628-1295)

## ✨ ความสามารถ

- 🎤 **พูดถาม–พูดตอบ** ภาษาไทย (Web Speech API ของเบราว์เซอร์ — ฟรี)
- ⌨️ **พิมพ์ถามได้** เป็นตัวสำรอง (เผื่อคนไม่อยากพูด)
- 😊 **จอใบหน้าแสดงอารมณ์** (รอ / ทักทาย / ฟัง / คิด / ตอบ / ผิดพลาด) + จอแชทแสดงบทสนทนา
- 👋 **ยกมือทักทาย** — ว่างเกิน 1 นาทีแล้วมีคนแตะจอ หุ่นโบกแขน (เซอร์โว + PCA9685) + หน้ายิ้ม + พูด "สวัสดีครับ ผมชื่อทีแอลบอท…"
- 🧠 ใช้ AI (**Gemini** ฟรีเป็นค่าเริ่มต้น / สลับเป็น **Claude** ได้) ตอบโดยอ้างอิง `college_data.json` + `saraburi_data.json` เท่านั้น
- 🏞️ **ตอบเรื่องสระบุรี** — วัด น้ำตก ธรรมชาติ ฟาร์ม ตลาด + สินค้า OTOP พร้อม **ระยะทางจากวิทยาลัย** และ **รูปสถานที่** (มีเมนูกดดูทีละหมวดโดยไม่ต้องใช้ AI)
- 🗺️ **แสดงแผนที่วิทยาลัย** อัตโนมัติเมื่อถามทาง/ตำแหน่งอาคาร + เสียงตอบผู้ชาย
- 👆 **ปุ่มคำถามยอดฮิต** กดถามได้ทันที
- 🔘 **ปุ่มกดจริง (GPIO)** บน Raspberry Pi กดแล้วเริ่มฟังเสียง + เปิดเครื่องแล้วรันเองแบบเต็มจอ (kiosk)
- 📷 **สแกน QR code** — เสียบเครื่องสแกน USB แล้วยื่น QR ให้หุ่น หุ่นตอบตามที่ตั้งไว้ใน `qr_codes.json` (เช่น ติด QR หน้าห้อง/บอร์ด)
- 🇬🇧 **สลับภาษาไทย/อังกฤษ** ได้บนจอ
- 🎬 **โหมดรอ** — ไม่มีคนใช้นานเกิน 90 วินาที เปิดวิดีโอแนะนำวิทยาลัยเต็มจอ แตะจอแล้วกลับมาหน้าถาม-ตอบ
- 📢 **ประกาศตามเวลา** — ตั้งข้อความให้หุ่นพูดเองตามเวลา/วันใน `announcements.json`
- ⭐ **ให้ดาว + หน้าสถิติ** (`/stats`) — ดูว่าคนถามเรื่องอะไรบ่อย และข้อไหนได้ดาวน้อย (ข้อมูลที่ควรเติม)
- ⚡ **จำคำตอบ** — คำถามซ้ำตอบได้ทันที ไม่ต้องรอ AI และไม่กินโควตา

## 🤖 หน้าตาของสิ่งประดิษฐ์

**ตู้/กล่องรูปหุ่นยนต์** สูงประมาณโต๊ะ ตั้งที่ประชาสัมพันธ์หรือหน้าอาคาร

```
        ┌─────────────────┐
        │   ◉        ◉    │  ← หัว: จอใบหน้า (/face)
        │      ‿‿‿        │     ตาขยับ เปลี่ยนอารมณ์ได้
        └────────┬────────┘
     ┌───────────┴───────────┐
     │ ┌───────────────────┐ │
     │ │ 💬 ถาม: สาขามีอะไร │ │  ← ตัว: จอ touch screen (/screen)
     │ │ 🤖 มีช่างยนต์ ...   │ │     แสดงแชท กด/พิมพ์ได้
     │ │ [🎤] [พิมพ์...]    │ │
     │ └───────────────────┘ │
     │        ( 🔴 )         │  ← ปุ่มกดจริง (GPIO) กดแล้วพูดได้เลย
     │      🔊 ลำโพง 🎤 ไมค์  │
     │   [Raspberry Pi ข้างใน]│  ← สมองซ่อนในกล่อง
     └───────────────────────┘
```

### 🔧 ชิ้นส่วน

| ชิ้นส่วน | หน้าที่ |
|---|---|
| **Raspberry Pi** | สมอง ซ่อนในกล่อง รันโปรแกรมทั้งหมด |
| **จอ touch screen** | ติดตรงลำตัว แสดงแชท กดปุ่ม อ่านคำตอบ |
| **จอใบหน้า** | ติดตรงหัว แสดงตาหุ่น (จอเล็กราคาถูกได้ ไม่ต้องสัมผัส) |
| **ปุ่มกดใหญ่** | กดแล้วหุ่นเริ่มฟัง |
| **ไมค์ + ลำโพง** | รับเสียงคนถาม / พูดตอบ |
| **WiFi** | ให้ Pi ต่อไปถาม AI (Gemini) |
| **เครื่องสแกน QR** (ไม่บังคับ) | สแกน QR แล้วหุ่นตอบข้อมูลที่ตั้งไว้ |

### 🎬 การใช้งานจริง

1. **เสียบปลั๊ก** → Pi เปิดเอง ขึ้นหน้าจอเอง ไม่ต้องมีคนมากด
2. คนเดินมา **กดปุ่ม** แล้วพูด *"วิทยาลัยมีสาขาอะไรบ้าง"*
3. **ตาหุ่นเปลี่ยน** เป็นท่าฟัง → ท่าคิด
4. หุ่น **พูดตอบด้วยเสียงผู้ชาย** + จอตัวขึ้นคำตอบเป็นตัวหนังสือ
5. ถามทาง เช่น *"โรงอาหารอยู่ไหน"* → **ขึ้นแผนที่** ด้วย
6. ถามเรื่องที่ไม่มีข้อมูล → **บอกให้ติดต่อเจ้าหน้าที่** ไม่แต่งเอง
7. **ยื่น QR** (เช่น ที่ติดหน้าห้อง) ให้เครื่องสแกน → หุ่นพูดข้อมูลของจุดนั้นทันที

### 🧠 Raspberry Pi คืออะไร ทำไมต้องใช้

**Raspberry Pi = คอมพิวเตอร์จิ๋วขนาดบัตรเครดิต** ทำหน้าที่เป็นสมองของหุ่น — ตอนทดสอบเรารันโปรแกรมบนโน้ตบุ๊ก ส่วน Pi คือ "คอมจิ๋วที่มาทำงานแทนโน้ตบุ๊ก" แล้วซ่อนไว้ในกล่อง

| งาน | ใครทำ |
|---|---|
| รันโปรแกรมหุ่น (`server.py`) | Pi |
| ส่งคำถามไปถาม AI ผ่าน WiFi | Pi |
| ส่งภาพออกจอ touch + จอใบหน้า | Pi |
| รับเสียงจากไมค์ / ส่งเสียงออกลำโพง | Pi |
| รับสัญญาณจากปุ่มกดจริง | Pi |

→ **จอ ไมค์ ลำโพง ปุ่ม — ทุกอย่างเสียบเข้า Pi** Pi คือศูนย์กลาง

**ทำไมไม่ใช้โน้ตบุ๊ก?** ใช้ได้ แต่ Pi เหมาะกว่าเพราะ
- **เล็ก** ซ่อนในกล่องได้ ดูเป็นหุ่นยนต์ ไม่ใช่โน้ตบุ๊กวางอยู่
- **ถูก** ~2,000 ฿ เทียบกับโน้ตบุ๊กเป็นหมื่น
- **เปิดเองอัตโนมัติ** เสียบปลั๊ก → หุ่นพร้อมใช้ (โค้ดทำไว้แล้ว)
- **มีขา GPIO** ต่อปุ่มหรือไฟ LED ได้ตรงๆ (โน้ตบุ๊กไม่มี)
- **ดูเป็นงาน IoT / สิ่งประดิษฐ์จริง**

> 💡 **ยังไม่อยากซื้อ Pi?** ใช้โน้ตบุ๊กซ่อนหลังกล่องไปก่อนได้ — ต่อจอ touch เข้าโน้ตบุ๊ก เสียงไทยใช้ได้ชัวร์ (Chrome บน Windows) แค่ปุ่มกดจริงจะยังใช้ไม่ได้ ให้กดปุ่มไมค์บนจอแทน

| ⬜ | **การ์ด microSD** | 32GB Class 10 / A1 | ~200 ฿ |
| ⬜ | **สาย micro-HDMI → HDMI** | 1 เส้นต่อ 1 จอ | ~100–150 ฿/เส้น |
| ⬜ | **ไมค์ USB** | ไมค์ตั้งโต๊ะ / ไมค์ประชุม | ~200–400 ฿ |

| ⬜ | **เคส + พัดลม/ฮีตซิงก์** | กันร้อน (เปิดทั้งวัน) | ~150–250 ฿ |

| มีแล้ว | ของ | สเปกที่แนะนำ | ราคาประมาณ |
|:---:|---|---|---|

| ⬜ | **ปุ่มกดใหญ่** | ปุ่มอาเขต 60mm มีไฟ LED | ~80–150 ฿ |

| ⬜ | **เครื่องสแกน QR** | แบบตั้งโต๊ะ USB รองรับ 2D/QR โหมดคีย์บอร์ด (USB HID) | ตามร้าน |

**🟢 ตัวกล่อง**

| มีแล้ว | ของ | ราคาประมาณ |
|:---:|---|---|
| ⬜ | ไม้อัด / แผ่นอะคริลิก / พิมพ์ 3D | ~300–800 ฿ |
| ⬜ | น็อต สกรู เทปกาวสองหน้า สีพ่น | ~100–200 ฿ |
| ⬜ | ปลั๊กพ่วง (Pi + จอ + ลำโพง) | ~200 ฿ |

**รวมประมาณ 4,700–7,000 ฿** (ไม่รวมจอ touch ที่มีแล้ว)

**💡 เคล็ดลับตอนซื้อ**
- **แนะนำ Pi 4 มากกว่า Pi 5** — Pi 4 มีช่องลำโพง 3.5mm, Pi 5 ไม่มี (ต้องใช้ลำโพง USB)
- ซื้อเป็น **ชุด kit** (Pi + อะแดปเตอร์ + การ์ด + เคส + สาย HDMI) ถูกกว่าซื้อแยก
- **เช็กจอ touch ที่มี** ว่าต่อแบบไหน: HDMI + USB → ใช้สาย micro-HDMI 1 เส้น / สายแพ (DSI) → ไม่ต้อง

> ⚠️ **ทดสอบเสียงก่อนซื้อครบ:** ระบบใช้เสียงจากเบราว์เซอร์ (Web Speech API) ซึ่งใช้ได้ดีบน Chrome/Windows แต่ **Chromium บน Raspberry Pi มักฟังเสียงพูดไม่ได้ และอาจไม่มีเสียงอ่านภาษาไทย** — แนะนำซื้อ Pi + ไมค์ + ลำโพงมาลองก่อน ถ้าไม่ทำงานจะเปลี่ยนไปใช้ Google Cloud Speech (มี `stt.py` / `tts.py` เตรียมไว้แล้ว มีโควตาฟรี)

### 👋 ต่อแขนโบกมือ (เซอร์โว MG996R + PCA9685)

| PCA9685 | ต่อกับ |
|---|---|
| VCC | Pi ขา 1 (3.3V) — ไฟเลี้ยงชิปเท่านั้น |
| GND | Pi ขา 6 (GND) **และ** GND ของตัวแปลงไฟเซอร์โว (กราวด์ต้องต่อร่วมกัน) |
| SDA / SCL | Pi ขา 3 (SDA) / ขา 5 (SCL) |
| V+ (ขั้วสกรูสีเขียว) | **ตัวแปลงไฟ 12V→5–6V ตัวที่สอง (≥5A)** จากแบต LiFePO4 |
| ช่อง 0 / 1 / 2 | เซอร์โว หัวไหล่ / ข้อศอก / คอ (สายน้ำตาล=GND, แดง=V+, ส้ม=สัญญาณ) |

> ⚠️ **ห้ามจ่ายไฟเซอร์โวจากขา 5V ของ Pi หรือใช้ตัวแปลงไฟตัวเดียวกับ Pi** — MG996R ตอนออกแรงกินไฟตัวละ 2A กว่า ไฟตกแล้ว Pi จะรีสตาร์ทกลางคัน

- ติดตั้ง: `bash robot/web/install_autostart.sh` (เปิด I2C + ลงไลบรารีเซอร์โวให้เอง) แล้วแก้ `SIMULATOR_MODE = False` ใน `robot/config.py`
- ตรวจว่าเห็นบอร์ด: `i2cdetect -y 1` ต้องเห็น `40`
- **แขนเอียงผิดมุม / โบกแรงไป** → แก้ตัวเลข `ARM_...` ใน `robot/config.py` ที่เดียว (องศา 0–180, ความเร็ว, จำนวนครั้งที่โบก)
- ลองสั่งโบกโดยไม่ต้องแตะจอ: `curl -X POST http://localhost:5000/greet`
- ถ้าเปิดเครื่องตอนยังไม่ได้เสียบบอร์ด หุ่นยังทำงานได้ตามปกติ แค่แขนไม่ขยับ (มีคำเตือนใน log)
