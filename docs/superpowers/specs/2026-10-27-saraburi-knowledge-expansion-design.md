# Design: ขยายฐานความรู้หุ่น — ข้อมูลสระบุรี

วันที่: 2026-10-27

## ภาพรวม

เพิ่มให้หุ่นตอบคำถามเกี่ยวกับจังหวัดสระบุรีได้ นอกเหนือจากข้อมูลภายในวิทยาลัย โดยอ้างอิงจากหนังสือ Saraburi Live and Life และข้อมูล OTOP สระบุรี รวบรวมจากแหล่งออนไลน์ หัวใจของงานเดิม (ห้ามตอบมั่ว) ยังคงอยู่ครบถ้วน

## แหล่งข้อมูล

- หนังสือ Saraburi Live and Life — fliphtml5 เป็น image-based ดึงตรงไม่ได้ รวบรวมข้อมูลเทียบเท่าจาก TAT, thai-tour.com, drivehub.com
- OTOP สระบุรี — komchadluek.net, my-best.com และแหล่งอื่น

## แนวทางที่เลือก: แยกไฟล์ + รวมตอน load (Approach B)

สร้าง `robot/saraburi_data.json` แยกต่างหาก `database.py` โหลดทั้งสองไฟล์และส่งรวมเข้า AI เป็นก้อนเดียว

## โครงสร้าง `saraburi_data.json`

```json
{
  "_คำอธิบาย": "ข้อมูลจังหวัดสระบุรี รวบรวมจากหนังสือ Saraburi Live and Life และ OTOP สระบุรี",
  "ท่องเที่ยวสระบุรี": {
    "น้ำตก": [...],
    "วัดและสถานที่ศักดิ์สิทธิ์": [...],
    "ธรรมชาติและสวน": [...],
    "ตลาดและแหล่งช้อป": [...],
    "ใกล้วิทยาลัย_อำเภอบ้านหมอ": [...]
  },
  "OTOP_สระบุรี": {
    "อาหารและขนม": [...],
    "งานหัตถกรรม": [...],
    "สมุนไพรและสุขภาพ": [...]
  }
}
```

แต่ละรายการมี field: `ชื่อ`, `อำเภอ`/`แหล่งผลิต`, `จุดเด่น` (และ `ระยะทาง` สำหรับหมวดใกล้วิทยาลัย)

## ไฟล์ที่เปลี่ยน

| ไฟล์ | การเปลี่ยนแปลง |
|------|--------------|
| `robot/saraburi_data.json` | สร้างใหม่ — ข้อมูลท่องเที่ยว + OTOP สระบุรี |
| `robot/config.py` | เพิ่ม `SARABURI_DATA_PATH` |
| `robot/database.py` | เพิ่ม `load_saraburi_data()` + `format_all_data()` |
| `robot/ai.py` | อัปเดต system prompt + signature `ask_ai(question, college_data, saraburi_data)` |
| `robot/web/server.py` | โหลด saraburi_data ตอนเปิดเซิร์ฟเวอร์ ส่งเข้า `ask_ai()` |
| `robot/simulator.py` | โหลด saraburi_data ส่งเข้า `ask_ai()` |
| `robot/test_saraburi.py` | สร้างใหม่ — test ชุดใหม่ |

## System Prompt ที่เปลี่ยน

จาก:
> "ตอบโดยอ้างอิงจากข้อมูลวิทยาลัยที่ให้ไว้ด้านล่างเท่านั้น"

เป็น:
> "ตอบโดยอ้างอิงจากข้อมูลวิทยาลัยและข้อมูลจังหวัดสระบุรีที่ให้ไว้เท่านั้น ห้ามแต่งหรือคาดเดาข้อมูลที่ไม่มีในฐานข้อมูลเด็ดขาด"

## Graceful Fallback

ถ้าไม่มีไฟล์ `saraburi_data.json` (เช่น clone ใหม่ยังไม่มี) `database.py` จะ return dict ว่างแทนที่จะ crash ระบบยังรันได้ตามปกติ

## Test Cases

1. โหลด `saraburi_data.json` สำเร็จ ไม่ error
2. ถามเรื่องท่องเที่ยวสระบุรี → ตอบจาก JSON (mock AI)
3. ถามเรื่อง OTOP สระบุรี → ตอบจาก JSON (mock AI)
4. ถามเรื่องที่ไม่มีในทั้งสองไฟล์ → ตอบ "ยังไม่มีข้อมูล" ไม่แต่งเอง
5. ไม่มีไฟล์ `saraburi_data.json` → server ยังขึ้นได้ปกติ

## สิ่งที่ไม่เปลี่ยน

- `college_data.json` — ไม่แตะ
- `ai.py` logic — แค่ขยาย system prompt และ signature
- UI ทั้งหมด — ไม่เปลี่ยน
- `run_web.bat` — ไม่เปลี่ยน
